# Projeto Hotel

Projeto em Python para acessar um banco MySQL de um hotel. Atualmente, cria as tabelas de quartos, hóspedes e hospedagens e permite consultar os números dos quartos.

## Requisitos

- Python 3
- MySQL
- Pacote `mysql-connector-python`

## Configuração

Configure a conexão com o MySQL antes de executar os scripts. Não coloque senhas diretamente no código nem neste README; prefira variáveis de ambiente.

## Execução

Crie as tabelas:

```bash
python Criar_Banco_de_Dados.py
